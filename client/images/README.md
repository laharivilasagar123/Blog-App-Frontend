# images/

This folder is a placeholder for any real image assets (logo, screenshots, blog thumbnails)
you'd like to add to BlogSphere.

The project currently uses CSS-based gradient placeholders instead of image files, so the app
works out of the box with zero binary assets and no broken image links. If you add real images,
reference them from here, e.g.:

```html
<img src="images/logo.png" alt="BlogSphere logo" />
```
